# conveo
Aplicación web para empresas que automatiza la gestión completa de convenios de prácticas estudiantiles. Permite gestionar convenios activos e históricos, calcular automáticamente fechas, horas y costes, generar recordatorios y facilitar la toma de decisiones en Recursos Humanos.⁠

# Reglas de Negocio
Cada centro solo puede tener 1 convenio activo
Cada estudiante solo puede tener asignado 1 convenio
Cada convenio puede tener varios estudiantes a la vez
Cada tutor de empresa puede tutorizar a varios estudiantes a la vez
